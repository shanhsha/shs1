1. 固定 + 自适应宽的底部导航

与 13-3.html 完全相同的布局：position: fixed 固定在屏幕底部， width: 100% 随屏幕自适应（手机满屏、桌面居中 480px），4 个项目各占 flex: 1 等分宽度。 区别只在图标实现——这里用 SVG Symbol，图标是真正的 <svg> 图形。

2. 关键代码

引入 iconfont 的 SVG 集合文件（会把 20 个 <symbol> 注入页面）：

<script src="./font/font_5244753_5641vvib7co/iconfont.js"></script>

图标用 <svg><use> 引用，颜色、大小都由 CSS 控制：

<svg class="shan_svg_icon"><use href="#icon-shangcheng"/></svg>

.shan_svg_icon { width: 24px; height: 24px; fill: currentColor; }

固定导航与徽章的 CSS 与 13-3 相同：

.shan_tabbar {
  position: fixed; left: 50%; bottom: 0; transform: translateX(-50%);
  width: 100%; max-width: 480px;        /* 宽度自适应 */
  display: flex;
  height: calc(58px + env(safe-area-inset-bottom));
}
.shan_tab { flex: 1 1 0; }                /* 4 项等分 */
.shan_icon_box { position: relative; }   /* 徽章定位基准 */
.shan_badge  { position: absolute; top: -7px; right: -11px; background: #ff3b30; }
.shan_dot    { position: absolute; top: -3px; right: -5px; border-radius: 50%; }

SVG 方式的特点：每个图标都是矢量图形，可以用 fill、width/height 精确控制， 也能对路径做动画；<use> 复用同一份 symbol，多处引用只占一份源码，且不需要下载字体文件。
