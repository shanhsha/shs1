2. 尺寸、颜色与线宽

SVG 是图形元素，用 width / height 控制尺寸，用 color → stroke:currentColor 控制颜色，用 stroke-width 控制线条粗细，放大缩小都不会失真。

4. 不依赖 JS：直接使用 SVG 源码

Lucide 的每个图标就是一段普通 SVG 标记，可以手写进 HTML（下面 4 个图标即 ./cdn/lucide/icons/ 中的文件内容），完全不需要脚本，也能用 CSS 随意改色、改线宽。

house
heart
rocket
sparkles

也可以把 SVG 当作图片文件引用（本地 ./cdn/lucide/icons/ 下已下载 8 个）：

<img src="./cdn/lucide/icons/rocket.svg"> —— 简单，但颜色固定，不能用 CSS 改色 
<svg class="lucide lucide-rocket" xmlns="http://www.w3.org/2000/svg" width="24" height="24"
     viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"
     stroke-linecap="round" stroke-linejoin="round">
  <path d="M4.5 16.5c-1.5 1.26-2 5-2 5s3.74-.5 5-2..." />
</svg>

5. 脚本调用与两种图标方式对比

本页引入的本地脚本与调用代码：

<script src="./cdn/lucide/lucide.min.js"></script>
<script>
  lucide.createIcons({ attrs: { "stroke-width": 2 } });
</script>
对比项 字体图标（Font Awesome / 13-1.html） SVG 图标（Lucide / 本页）
实现方式@font-face 加载字体，::before 打出字符内联 <svg> 元素或引用 .svg 文件
尺寸控制font-size（可配 fa-2x 等）width / height，矢量缩放不模糊
颜色控制整个图标一个 colorcolor（stroke）或 fill，可按 path 分别设置
线条粗细由字体设计决定，无法修改stroke-width 随时可改
加载开销字体文件一次加载，全站复用内联会增加 HTML 体积；文件方式按请求加载
动画对整个字形做 transform 动画可对路径、描边、虚线做精细动画
可编辑性需要字体编辑工具直接改 path 的 d 属性即可

字体图标胜在“像文字一样好用、加载一次全站可用”；SVG 图标胜在“可塑性强：多色、变线宽、可裁剪、可做路径动画”。两种方式本地文件都放在 ./cdn/ 目录，断网也能正常显示。
