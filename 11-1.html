单海晟的CSS长度单位

绝对单位、相对单位与视口单位一览

1. 绝对长度单位

长度固定，不会随屏幕或父元素变化。以下条形按各自的 CSS 值渲染。

width: 96px
width: 1in
width: 1cm
width: 10mm
width: 72pt
width: 6pc
单位 含义 换算（以 96dpi 计算）
px像素1px = 1px
in英寸1in = 96px
cm厘米1cm = 37.8px
mm毫米1mm = 3.78px
pt点1pt = 1.333px
pc派卡1pc = 16px
Q四分之一毫米1Q = 0.945px

屏幕开发中最常用的是 px；cm、mm、in 主要用于打印样式。

2. 相对长度单位

相对单位会随参考对象（父元素、根元素或字体）变化。此处根字体为 16px，宿父容器宽 100%。

width: 16em
width: 16rem
width: 50%
width: 20ex
width: 30ch
单位 参考对象
%父元素的对应属性
em当前元素的字体大小
rem根元素（html）的字体大小
ex当前字体的 x 高度
ch数字 “0” 的宽度

rem 只参照根字体，做响应式排版时比 em 更稳定、更易预测。

3. 视口单位

相对浏览器视口尺寸计算，常用于全屏与响应式布局（改变窗口大小可看到变化）。

width: 40vw
width: 40vmin
width: 40vmax
height: 8vh
单位 含义
vw视口宽度的 1%
vh视口高度的 1%
vminvw 与 vh 中较小的 1%
vmaxvw 与 vh 中较大的 1%

在移动端要注意地址栏伸缩带来的跳动：可用新单位 dvh、svh、lvh 分别表示动态、最小、最大视口高度。

4. 其他常用单位

现代 CSS 还提供了按内容、行高与容器计算的单位。

  • fr（网格弹性份数）
  • lh / rlh（行高）
  • cqw / cqh（容器查询尺寸）
  • cap / ic（大写高度 / 表意文字宽度）
  • deg / turn（角度）
  • s / ms（时间）

单位可以混合计算，例如 width: calc(100% - 2rem)。
